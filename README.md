# Group3 - Aplikasi Pasar Tani

## Deskripsi Singkat
**Pasar Tani** adalah adalah sebuah platform digital berbasis mobile yang dikembangkan menggunakan Flutter dan terintegrasi dengan Firebase. Aplikasi ini dirancang untuk memfasilitasi transaksi jual beli hasil pertanian secara langsung, khususnya antara petani atau produsen. Melalui Pasar Tani, pengguna dapat mendaftar baik sebagai pembeli maupun sebagai penjual (toko), sesuai dengan kebutuhan mereka. Aplikasi ini menyediakan berbagai fitur penting seperti manajemen produk, keranjang belanja, pencarian produk, pemetaan lokasi, serta sistem checkout untuk menyederhanakan proses perdagangan. Selain itu, pengguna juga dapat mengelola inventori, melakukan pemesanan, serta memantau riwayat transaksi secara praktis dan efisien.

## 📦 Cara Menjalankan Program

Berikut langkah-langkah untuk menjalankan aplikasi ini secara lokal:

### 1. Persiapan Lingkungan
Pastikan telah menginstal:
- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- [Android Studio](https://developer.android.com/studio) atau emulator lainnya
- Firebase CLI (jika ingin testing cloud function opsional)

### 2. Clone Repository
```bash
git clone https://github.com/anisaideliaa/FPTekberGroup3.git 
```

### 3. Install Dependencies
```bash
flutter pub get
```

### 4. Konfigurasi Firebase
- Buat project di [Firebase Console](https://console.firebase.google.com/)
- Aktifkan Authentication (Email/Password)
- Buat Firestore Database
- Unduh file `google-services.json` dan tempatkan di folder `android/app/`
- (Opsional) Untuk web atau iOS, sesuaikan pengaturan masing-masing platform

### 5. Jalankan Aplikasi
```bash
flutter run
```
